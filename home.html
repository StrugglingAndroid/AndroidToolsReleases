Android 综合工具箱

一款面向 Android 开发者的辅助工具，集批量签名、渠道打包、APK 加固、 增量包生成、图标生成等常用功能于一体，简单易用、开箱即用。

核心功能
✍️批量签名
批量对多个 APK 文件进行签名，支持自定义输出目录。
📦渠道打包
快速生成多渠道包，支持并行处理，速度快。
🛡️APK 加固
对 APK 进行加固保护，支持多架构。
🎨图标生成
一键生成多种尺寸的应用图标资源。
🔄增量包
生成 APK 增量更新包，显著减少更新体积。
🔍APK 信息
批量查看包名、版本号、签名信息等。
系统要求
  • Windows 7 SP1 及以上版本
  • 已安装 Java 8 或更高版本（渠道打包、加固所需）
  • 已配置 Android SDK
原始 APK 文件不会被修改，所有操作都会生成新文件 · 感谢使用 Android 综合工具箱
